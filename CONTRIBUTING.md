# Contributing

Thanks for your interest in contributing!

## How to contribute

1. Fork the repo and create your branch from `main`.
2. Install dependencies:

   ```bash
   composer install
   npm install
   ```

3. Make your changes with clear, focused commits.
4. Run tests before submitting:

   ```bash
   php artisan test --compact
   ```

5. Open a pull request with a concise description of the change and any relevant context.

## Code style

- Follow existing patterns in the codebase.
- Keep changes small and focused.
- Avoid adding new dependencies without prior discussion.

## Reporting issues

If you find a bug or have a feature request, please open an issue with steps to reproduce and expected behavior.
