# Code of Conduct

We want this project to be a welcoming, respectful place for everyone.

## Our standards

- Be respectful and considerate in words and actions.
- Assume good intent and focus on constructive feedback.
- Avoid harassment, discrimination, and hostile behavior.

## Enforcement

Project maintainers are responsible for enforcing these standards. If you experience or witness unacceptable behavior, please reach out to a maintainer privately.
